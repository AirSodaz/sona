# Sona 用户指南

[English](user-guide.md) | [简体中文](user-guide.zh-CN.md) | [项目 README](../README.zh-CN.md)

这份指南面向桌面端用户，帮助您完成 Sona 的安装、首次配置、本地转录、文本整理与导出。

## 1. Sona 适合做什么

Sona 是一款以隐私优先为目标的转录编辑器，适合希望默认在本机完成语音转文字流程，而不是先把音频上传到云端的用户。

如果您有以下需求，Sona 会比较适合：

- 用 `实时录音` 记录会议、课堂、访谈或语音笔记
- 用 `批量转录` 处理已有的音频或视频文件，配备汇总看板与分组队列，并支持在消息中心实时取消
- 用 `项目中心`、`收件箱 (Inbox)` 与 `回收站` 组织已保存内容，并为项目绑定专属处理流水线
- 在按时间轴组织的编辑器中逐段检查文本、说话人标签和时间戳，支持加粗、斜体、下划线、删除线（`Ctrl + Shift + S`）与行内代码
- 使用 `说话人档案` 与 `说话人校对` 确认候选或匿名说话人分组
- 在自行配置服务后，使用 `LLM 润色`、`翻译` 或 `AI 摘要`
- 当批量改写需要回退时，从 `版本快照` 中恢复选中的修改
- 将结果导出为常见字幕、Markdown 或纯文本格式，或一键复制到剪贴板
- 使用 `端到端加密云同步`（WebDAV 与 S3 兼容对象存储 E2EE）在多台桌面与 Android 设备间同步文稿、词库与设置
- 按需启用 `语音输入法`，把识别结果直接输入到其他应用
- 在 `存储管理` 中配置自定义 FFmpeg 路径及历史音频自动清理策略

如果您主要是为了 `实时字幕` 而来，请直接查看 `实时录音` 章节；如果您主要想整理已经保存的内容，可以直接跳到 `项目中心与收件箱`；如果您主要需要处理说话人或版本回退，请查看 `转录编辑与播放`；如果您主要想用 `语音输入法`，请直接查看 `导出与设置` 中关于 `设置 > 语音输入法` 的说明。

## 2. 安装与启动

对大多数用户来说，最简单的方式是直接安装最新发布版本：

- 从 [GitHub Releases](https://github.com/AirSodaz/sona/releases/latest) 下载 Sona。
- 启动应用。
- 如果您需要从源码构建，请参考[开发指南](development.zh-CN.md)。

Sona 首次打开时，可能会直接进入 `首次运行设置`。如果您暂时跳过，后续应用会继续通过提醒横幅提示您完成离线初始化。

### 需要 CLI？

如果您需要无状态的命令行文件/实时转录、模型管理、转录导出或本地 HTTP API 服务，请查看专门的 [CLI 指南](cli.zh-CN.md)。本指南只覆盖桌面端日常使用流程。

## 3. 首次运行设置

在本地离线转录可用之前，Sona 需要先完成离线模型初始化。

### 前置条件

- Sona 可以正常启动。
- 如果您准备直接下载推荐模型包，需要联网。

### 操作步骤

1. 启动 Sona，等待 `首次运行设置` 出现。
2. 阅读欢迎步骤。Sona 推荐的首条成功路径是 `麦克风 -> 实时录音`。
3. 点击 `继续`。
4. 在模型步骤点击 `下载推荐模型`。如果所需模型已经存在，界面会直接显示 `继续`。
5. 等待推荐离线模型下载并解压完成。
6. 进入麦克风步骤并允许麦克风访问权限。
7. 如果权限被拒绝，请在处理系统权限提示后点击 `重新请求权限`。
8. 选择您希望 `实时录音` 默认使用的麦克风。
9. 点击 `前往实时录音`。

### 完成后会发生什么

- Sona 会应用推荐的本地离线转录配置。
- 应用会切换到 `实时录音`。
- 如果设置仍未完成，提醒横幅可以再次打开引导。

### 说明

- 首次引导的目标是尽快让本地离线转录进入可用状态。
- 您可以在引导过程中点击 `稍后`，之后再通过提醒横幅返回。
- 如果您主动关闭提醒横幅，它将不再在首页显示，直到设置完成。
- 后续可以在 `设置 > 模型设置` 中改用其他模型。
- 默认麦克风可以在 `设置 > 输入设备` 中重新调整。

## 4. 实时录音

如果您希望边录音边生成转录内容，请使用 `实时录音`。

### 前置条件

- 您已经完成 `首次运行设置`，或已在 `设置 > 模型设置` 中配置 `实时录音模型`。
- 如果要从麦克风录音，系统已经授予麦克风权限。

### 操作步骤

1. 点击 `实时录音` 页签。
2. 在开始录音前，从下拉框选择输入源：
   `麦克风` 或 `桌面音频`。
3. 点击 `开始录音`。
4. 通过波形和计时器观察采集状态。
5. 需要临时中断时使用 `暂停`，要结束本次录音时使用 `停止`。
6. 点击 `参数设置`，按需调整 `字幕模式` 或 `语言`。
7. 如果需要悬浮字幕窗口，请打开 `实时字幕`。
8. 如需调整字幕浮窗的置顶、点击穿透、尺寸、宽度、字体与背景颜色或启动行为，请前往 `设置 > 字幕设置`。

### `实时字幕` 是做什么的

- `实时字幕` 是 `实时录音` 页面里的 `悬浮字幕（系统音频）` 开关，适合您主要想把系统音频以悬浮字幕方式显示出来的场景。
- 它可以单独开启，不需要先开始录音；如果您之后再开始 `实时录音`，两者也可以并行使用。
- `设置 > 字幕设置` 负责控制字幕窗口的启动行为、置顶、点击穿透、字体大小、宽度、字体与背景颜色和背景透明度。

### 完成后会发生什么

- 新的转录分段会实时出现在右侧编辑器中。
- 当前活跃分段会跟随录音状态变化。
- 录音仍在进行时，Sona 也可以先把这次会话显示成 `项目中心` 里的一个 `草稿` 条目。
- 停止录音后，当前转录内容仍可继续编辑、润色、翻译、导出，并在之后从 `项目中心` 重新打开；Sona 会直接完成这条草稿，而不是再额外创建第二条记录。
- 如果您当时不在某个项目上下文里，保存后的条目通常会先进入 `Inbox`。

### 说明

- 默认情况下，`Ctrl + Space` 用于开始或停止实时录音。
- 录音过程中按 `Space` 可以暂停或继续。
- `参数设置` 主要控制 `字幕模式` 和 `语言`，不是完整的 LLM 润色入口。
- 如果提示缺少模型，请重新完成引导，或到 `设置 > 模型设置` 手动配置。

## 5. 批量转录

如果您已经有音频或视频文件，并希望在后台排队转录，请使用 `批量转录`。

### 前置条件

- 您已经在 `设置 > 模型设置` 中配置 `批量转录模型`。
- 输入文件属于支持的音频或视频格式。

### 操作步骤

1. 点击 `批量转录` 页签。
2. 将文件拖入导入区域，或者点击 `选择文件`。
3. 添加一个或多个文件到队列。
4. 观察队列顶部的汇总看板（显示总任务数、待处理、处理中、已完成与失败统计指标）。
5. 在分组队列列表中展开或折叠不同状态的文件组，并可点击清空菜单按需选择 `清空已完成` 或 `清空全部`。
6. 如需继续追加文件，点击 `添加更多文件`。
7. 点击 `参数设置`，按需调整 `字幕模式` 或 `语言`。
8. 文件处理完成后，在主编辑器中检查结果。

### 完成后会发生什么

- Sona 会按 `待处理`、`处理中`、`完成`、`失败` 等状态管理队列。
- 在任务处理期间，您可以通过顶栏的 `消息中心` 查看实时处理进度；如果需要放弃当前或后续任务，可以点击停止按钮实时取消批量转录。
- 已完成的文件会载入主编辑器，供您继续编辑、翻译和导出。

### 说明

- 如果未配置离线批量模型，Sona 会重新打开引导，而不是直接开始转录。
- `设置 > 模型设置` 中的 `批量 VAD 分割`、`VAD Buffer Size` 与 `Max Concurrent Transcriptions` 会影响批处理体验。关闭批量 VAD 后，本地批量转录会整段识别文件。
- 批量 VAD 分割适用于所有本地引擎，包括 llama.cpp 预设（Qwen3-ASR）。默认伴生模型为 Silero VAD v5；模型目录中亦提供 Silero v4 与 TEN VAD。
- 本地模型目录提供清晰的品牌标识、标签筛选与推荐评级（如推荐 FireRedASR2-AED 与 FunASR Nano）。

## 6. 转录编辑与播放

当 Sona 生成转录分段之后，右侧编辑器就是整理文本、说话人归属、播放时间点和已保存版本的主要编辑界面。

### 前置条件

- 您已经通过 `实时录音`、`批量转录` 或 `项目中心` 载入了转录内容。

### 操作步骤

1. 在编辑器中查看分段列表。
2. 点击时间戳可以跳转到对应播放位置。
3. 双击分段文本，或使用编辑按钮进入编辑状态；若已启用双语翻译，双击译文区域或点击译文悬浮编辑按钮可独立行内编辑译文，按 `Enter` 保存，按 `Escape` 放弃。
4. 在只读分段上点击右键，可以使用 `复制`、`全选` 与 `录入声纹样本`（截取当前片段音频绑定到说话人档案）；编辑时点击右键，可以使用 `剪切`、`复制`、`粘贴`、`全选`、`加粗`、`斜体`、`下划线` 和 `删除线`。键盘菜单键或 `Shift + F10` 会打开同一菜单。
5. 按 `Ctrl + Shift + S` 可快速为选中文字添加或去除删除线。
6. 按 `Enter` 保存当前分段。
7. 按 `Shift + Enter` 在光标位置拆分当前分段。
8. 使用合并按钮将当前分段与下一段合并。
9. 使用删除按钮在确认后删除分段。
10. 按 `Ctrl + F` 搜索当前转录内容。
11. 如果当前条目带有音频，使用底部播放器进行播放、暂停、跳转、倍速和音量控制。
12. 如果分段显示说话人标签，点击说话人徽标即可把整个说话人分组绑定到某个 `说话人档案`、展开更多全局档案，或把该分组恢复为匿名标签。
13. 导出前如果需要集中检查说话人，打开转录标题栏里的 `说话人校对`。这里可以按 `待审`、`候选建议`、`匿名`、`已识别`、`已审阅` 或 `全部` 筛选，预览每个分组的前几个片段，跳到首段，确认当前标签，应用候选档案，手动绑定其他档案，或恢复匿名标签。
14. 当当前转录是已保存且非草稿的项目条目时，可以从标题栏打开 `版本快照`。您可以比较某个旧快照与当前转录的差异，恢复选中的差异行，或整份回退到该快照。

### 完成后会发生什么

- 您可以逐段修正文本。实时转录时，编辑器还包含预测光标动效指示出字进度。
- 时间轴与播放位置会保持联动。
- 说话人修正会应用到同一说话人分组下的所有分段。
- 从版本快照恢复前，Sona 会先保存当前转录，所以回退操作本身也可以继续追溯。

### 说明

- 只有在编辑某一段时，编辑工具栏才会显示。
- 工具栏支持 `撤销`、`重做`、加粗、斜体、下划线、删除线（`Ctrl + Shift + S`）和拆分分段。
- 搜索结果可以在不同分段之间快速跳转。
- 只要当前转录有分段，标题栏就会显示 `说话人校对` 入口；如果这份转录没有说话人元数据，校对列表可能为空。
- `说话人档案` 在 `设置 > 词汇` 中创建；项目设置可以选择当前项目启用哪些档案。档案会帮助候选建议和自动匹配，但您仍然可以人工确认、重新绑定或恢复匿名标签。
- `版本快照` 只会显示在已保存、非草稿、且不是临时 `current` 的项目条目上。Sona 会在 `LLM 润色`、`翻译`、`重新转录` 等批量改写前，以及执行恢复前保存快照。

## 7. LLM 润色、翻译与摘要

Sona 的 LLM 功能是可选能力。离线转录本身不依赖它，但 `LLM 润色`、`翻译` 与 `AI 摘要` 需要先在 `设置 > LLM 服务` 中完成配置。

### 前置条件

- 您已经有转录分段。
- 您已经在 `设置 > LLM 服务` 中配置了要使用的功能。

### LLM 服务设置步骤

1. 打开 `设置 > LLM 服务`。
2. 在 `功能模型绑定` 中分别为 `润色模型`、`翻译模型` 和 `摘要模型` 指定模型。
3. 在 `Provider 凭据` 中展开要使用的 provider，填写相应的连接信息，例如 `Base URL`、`API Key`、`Endpoint`、`Deployment Name` 或 provider 特有字段。
4. 如果所选模型支持，可以启用 `深度思考模式` 并选择 `思考程度`。
5. 点击 `测试连接` 验证配置。
6. 确认所需功能已经绑定模型后，再返回主界面使用。

### `LLM 润色` 操作步骤

1. 确认 `设置 > LLM 服务` 中已经指定 `润色模型`。
2. 点击 `LLM 润色` 按钮。
3. 按需选择：
   `LLM 润色`、`重新转录`、`撤销`、`重做`、`高级设置`。
4. 如果需要管理 `Auto-Polish`、`Auto-Polish Frequency`、`关键词`、`润色模式`（去冗易读 Clean、逐字精准 Verbatim、书面规整 Formal）与 `自定义上下文`，请打开 `高级设置`。

### `翻译` 操作步骤

1. 确认 `设置 > LLM 服务` 中已经指定 `翻译模型`。
2. 点击 `翻译` 按钮。
3. 选择目标语言。
4. 点击 `开始翻译` 或 `重新翻译`。
5. 翻译完成后默认开启双语对照显示，您可随时使用 `显示双语` 或 `隐藏双语` 切换视图，并可直接在编辑器中双击译文进行行内编辑修正。

### `AI 摘要` 操作步骤

1. 确认 `设置 > LLM 服务` 中已经启用 `AI 摘要`，并指定 `摘要模型`。
2. 打开任意一个已经有分段内容的转录。
3. 从转录界面打开摘要编辑区。
4. 如果需要切换下一次生成所使用的摘要模板，可在 `通用`、`会议` 或 `课堂` 之间切换。
5. 点击 `生成` 创建当前摘要；之后如需替换它，点击 `重新生成`。
6. 如果需要微调措辞，可直接编辑摘要文本。焦点离开编辑区后，Sona 会自动保存。
7. 如果需要把摘要用于其他地方，点击 `复制`。

### 完成后会发生什么

- `LLM 润色` 会直接更新转录文本。
- `翻译` 会把翻译结果保存到每个分段，并可显示在原文下方。
- `AI 摘要` 会以“当前摘要记录”的形式保存在转录旁边，不会改写原文。
- 对已保存且非草稿的转录，批量改写会创建 `版本快照`，之后可以从编辑器里重新查看。

### 说明

- `润色模型`、`翻译模型` 与 `摘要模型` 是分开配置的。您可以让它们共用同一个 provider，也可以分别设置。
- 翻译可以使用 `Google Translate (Free)`、`Google Translate (API)` 这类专用翻译 provider；`LLM 润色` 则需要真正的 LLM provider 与模型。
- `AI 摘要` 也需要真正的 LLM provider 与模型，不支持 `Google Translate` 系列 provider。
- 您可以在 `设置 > LLM 服务` 中关闭 `AI 摘要`。关闭后摘要面板会隐藏，并且不会继续生成新的摘要，但已有 sidecar 摘要数据会保留。
- 如果 `AI 摘要` 还没有完成 LLM 配置，您仍然可以先打开摘要编辑区，手动编写或修改摘要文本。
- 每份转录只会保留一条“当前摘要记录”。切换模板只会改变下一次生成所使用的模板，或项目默认模板，不会为每个模板各自保存一份独立摘要。
- 当前支持的翻译目标语言包括 `简体中文`、`English`、`Japanese`、`Korean`、`French`、`German`、`Spanish`。
- 只有当当前转录来自已保存的项目条目时，菜单中才会出现 `重新转录`。
- 当前摘要结果支持直接编辑、自动保存和复制复用。
- 如果润色、翻译或重新转录改动过多，可以从转录标题栏打开 `版本快照`，恢复选中的差异行，或整份回退到某个旧快照。

## 8. 导出转录

只要编辑器里至少有一个分段，就可以导出。

### 前置条件

- 当前编辑器中已经有转录内容。

### 操作步骤

1. 点击顶部栏中的 `导出转录` 按钮。
2. 在 `导出转录` 弹窗中填写 `文件名`。
3. 选择 `导出目录`。
4. 选择输出格式：
   `SubRip (.srt)`、`WebVTT (.vtt)`、`JSON (.json)`、`Plain Text (.txt)`。
5. 选择导出模式：
   `原文`、`译文`、`双语`。
6. 点击 `导出`。

### 完成后会发生什么

- Sona 会把转录内容写入您选择的路径和格式。
- 如果已有翻译内容，您可以导出纯译文或双语版本。

### 说明

- 只有在当前转录至少包含一个翻译分段时，`译文` 和 `双语` 才可用。
- `原文` 模式始终可用。
- 如果导出结果或交付前检查需要说话人标签，请先运行 `说话人校对`，把候选和匿名分组确认好。

## 9. 项目中心、流水线、收件箱与回收站

如果您希望在不离开主编辑面的前提下系统整理录音和导入内容，就使用 `项目中心`。

### 浏览视图与组织结构

- `项目中心`：管理所有自定义项目，并可在应用顶栏左侧的下拉菜单中随时切换当前激活的项目。
- `收件箱 (Inbox)`：承接尚未归入任何特定项目的录音和导入内容。
- `全部内容`：跨项目和收件箱 (Inbox)总览所有已保存条目。
- `回收站`：存放软删除的录音和导入内容，支持恢复原状或彻底清空。

### 操作步骤

1. 打开 `项目中心`（或通过左侧边栏导航）。
2. 使用边栏在 `全部内容`、`收件箱 (Inbox)`、`回收站` 和各个项目之间切换。
3. 点击 `新建项目`，输入项目名称、描述，并选择专属的项目图标与主题色。
4. 当您希望后续工作自动应用某套规范时，先在顶栏或项目列表中将其设为当前活跃项目。
5. 在项目顶部直接点击 `开始实时录音` 或 `开启批量导入`，即可在保留当前项目上下文的前提下开始新工作。
6. 点击任意已保存条目，即可在右侧详情面板中直接打开并继续编辑，无需离开项目中心。
7. 在项目上点击右键可使用 `打开` 或 `项目设置`；在条目上点击右键可使用 `打开`、`重命名` 或 `删除`（删除将移入回收站）。聚焦对应行后，键盘菜单键或 `Shift + F10` 触发相同菜单。
8. 在多选模式下，可以批量为条目分配项目、移入收件箱或批量移入回收站。
9. 使用搜索、筛选、排序以及列表 / 网格 / 表格视图切换快速缩小查看范围。
10. 打开 `回收站` 视图，可以查看已软删除的条目，支持单项/批量 `恢复` 或 `彻底删除`。

### `项目设置` 与处理流水线（Pipeline）

每个项目都拥有专属的自动化处理流水线（Pipeline Engine）：

1. 打开某个项目并点击 `项目设置`。
2. 自定义项目名称、描述、图标（系统图标与自定义 Emoji）和主题颜色。
3. 配置该项目的流水线默认值：
   - `默认摘要模板`：为该项目新生成的摘要指定模板（通用、会议、课堂或自定义）。
   - `默认翻译语言`：指定该项目常用的目标翻译语言。
   - `默认润色模式` 与 `默认润色上下文`：定义专属的指令式润色模式（去冗易读、逐字精准、书面规整）与领域提示词。
   - `导出文件名前缀`：导出文件时自动附加项目标识前缀。
4. 绑定专属规则集：
   - 独立启用或关闭该项目的 `文本替换` 规则集。
   - 独立启用或关闭该项目的 `热词` 词库。
   - 独立启用或关闭该项目的 `润色关键词` 规则。
   - 勾选该项目专属的 `说话人档案`。
5. 点击 `保存` 保留修改；若点击 `删除项目`，可选择将项目内条目移回 `收件箱 (Inbox)` 或一并移入 `回收站`。

### 完成后会发生什么

- 顶栏项目下拉菜单会始终指示当前激活的工作上下文。
- 在项目内发起的新工作会自动套用该项目的流水线规则，无需每次手动配置。
- 软删除的数据进入回收站，避免误删导致重要文稿丢失。

### 说明

- `全部内容` 用于总览浏览已保存内容，不会覆盖当前项目的默认设置。
- 未分配到特定项目的新录音和导入内容默认存放在 `收件箱 (Inbox)`。
- 录音仍在进行时，活跃的实时录音会以 `草稿` 状态显示在项目列表中。停止录音后，该条目会直接变为已保存的最终条目。
- 项目图标支持系统内置图标、推荐 Emoji 与自定义 Emoji。
- 已保存的录音和导入条目也支持通过独立的重命名流程修改标题和图标，这与 `项目设置` 是分开的。
- 如果在项目转录中绑定了全局说话人档案，Sona 会将该档案添加到当前项目的已启用说话人档案中，方便后续工作自动进行候选匹配。
- 如果在项目设置抽屉包含未保存修改时切换离开项目，Sona 会提示您是否先放弃这些更改。

## 10. 导出与设置

如果您准备把文件导出，就使用 `导出`；如果您要管理应用级默认行为，就使用 `设置`。如果您需要重新打开或整理已保存的内容，请返回 `项目中心`，而不是寻找独立的已保存列表视图。

### 导出提示

- 当转录整理完成后，使用顶部栏中的 `导出` 按钮。
- 上文 `8. 导出转录` 详细列出了当前支持的格式与模式。

### 设置区域索引

Sona 提供 14 个功能清晰的设置区域：

- `设置 > 常规`：界面主题、语言、字体、系统托盘、更新检查，以及 `诊断` 与本地轻量备份导入/导出。
- `设置 > 仪表盘`：全局内容统计、录音时长分布、说话人声纹覆盖率与 LLM Token 消耗趋势。
- `设置 > 输入设备`：麦克风选择、系统音频设备、麦克风增强、`保持麦克风激活`（低延迟预热）与录音时静音。
- `设置 > 字幕设置`：实时字幕浮窗的启动行为、点击穿透锁定、置顶、字体大小、宽度、字体与背景颜色与背景透明度。
- `设置 > 语音输入法`：启用全局听写、设置快捷键、选择 `按住说话` 或 `切换模式`，并查看依赖就绪状态。
- `设置 > 模型设置`：`实时录音模型`、`批量转录模型`、CTC 强制对齐、声纹分割灵敏度（宽松/平衡/严格）、批量 VAD 分割、VAD 伴生模型切换（默认 Silero v5）、离线模型下载管理与目录镜像切换。
- `设置 > 词汇`：划分为三个子标签页——`识别与纠偏`（管理全局文本替换规则与热词词库）、`提示词与上下文`（文本润色上下文预设与摘要模板）以及 `说话人档案`（声纹特征库与样本管理）。
- `设置 > 自动化`：监控本地文件夹规则，在放入音频/视频文件时自动完成转录、润色、翻译与格式导出。
- `设置 > 存储管理`：统一查看数据与模型存储路径、自定义 FFmpeg 路径、磁盘占用分析、历史音频保留自动清理策略与 WebView 缓存清理。
- `设置 > 云同步`：端到端加密（E2EE）跨设备同步库，支持 WebDAV 与 S3 兼容对象存储（AWS S3、Cloudflare R2、MinIO 等）、同步库 ID 与多端配对、主密码与应急恢复密钥、同步范围预设与冲突中心。
- `设置 > API 服务`：本地 HTTP API 服务的监听地址、端口、Bearer 认证密钥、IP 白名单与服务限制。
- `设置 > LLM 服务`：功能模型绑定、思考程度选项与 Provider 凭据配置。
- `设置 > 快捷键`：实时录音、音频播放、搜索、项目导航与编辑器快捷键（含删除线 `Ctrl + Shift + S`）。
- `设置 > 关于`：版本信息、Release 通道标识、开源协议、应用日志与调试入口。

### 语音输入法

- 当您希望把语音直接听写输入到聊天软件、文档、表格或其他应用程序时，使用 `语音输入法`。
- 打开 `设置 > 语音输入法`，启用 `语音输入法`，分配全局快捷键，并选择 `按住说话 (Hold)` 或 `切换模式 (Toggle)`。
- `按住说话` 适合短促输入；`切换模式` 适合长时间听写。
- `语音输入法` 复用相同的离线实时转录体系，因此您需要配置好可用的 `实时录音模型`、所需的 `VAD` 伴生模型以及有效的音频输入设备。
- 该设置页面还会清晰显示当前阻塞状态（快捷键、模型、VAD、输入设备或后台预热就绪情况）。
- `设置 > 输入设备 > 保持麦克风激活` 默认关闭。如果您希望在空闲时保持麦克风预热以降低输入首字延迟，可将其开启；如果您希望在未录音、未听写且未预览输入时让 Sona 彻底释放麦克风，请保持关闭。

### 云同步（端到端加密）

Sona 拥有专为隐私打造的跨设备增量同步系统：
1. **端到端加密（E2EE）**：所有文稿、分类、词库与设置在离开本机前均由您的主密码进行加密，远端 WebDAV 服务器或 S3 兼容对象存储桶无法读取明文。
2. **凭据安全与主密码**：
   - `端到端主密码`：用于本地加密和解密同步库的核心密码。
   - `应急恢复密钥`：在初次创建同步库时由系统生成。若遗忘主密码，可使用恢复密钥解锁并重置密码。恢复密钥绝不会以明文保存在云端或本地。
3. **多设备配对（Vault ID 与配置导入导出）**：首台设备初始化后会生成十六进制的同步库 ID。在其他桌面电脑或 Android 设备上导入配对令牌或输入该 ID、存储端点和主密码即可快速配对。
4. **数据同步范围预设（Sync Scopes）**：
   - `内容模式`：仅同步转录文稿、摘要历史与项目分类；
   - `标准模式`：内容模式 + 说话人档案 + 热词词库 + 提示词与摘要模板 + 应用设置；
   - `完整模式`：全部项目数据 + 自动化监控规则与运行日志。
5. **冲突中心（Conflict Center）**：当多台设备发生离线并发编辑时，Sona 会在设置中提供冲突列表，直观对比当前版本与冲突版本，支持保留当前、使用冲突版本或保留两者。
6. **顶栏同步状态灯（SyncHeaderPill）**：常驻顶栏，实时展示同步状态（同步就绪、正在同步、锁定、错误等），点击可快速打开同步设置。
7. **录音音频不上传**：音频录音文件保留在本地机器上，不会上传云端，保障绝对声纹隐私并节约云存储。
8. **旧 WebDAV 备份归档**：页面底部提供一次性导入旧版整包备份的兼容入口，Sona 不再创建新的远端整包备份。

### 存储管理

在 `设置 > 存储管理` 中，您可以全面掌控 Sona 的本地磁盘占用：

- **统一存储位置**：清晰查看应用数据目录、模型目录与临时缓存路径，支持一键打开系统文件夹。
- **自定义 FFmpeg 路径**：如果系统缺少全局 FFmpeg 或需要特定编解码版本，可在此手动浏览并指定本地 `ffmpeg` 可执行文件。
- **历史音频保留策略**：支持设定音频保留周期（`永久保留`、`立即删除`、`7天`、`30天`、`90天`、`180天`、`365天`）。到期后 Sona 会自动清理本地原始音频以释放空间，而转录文本和摘要将完整保留。
- **WebView 缓存清理**：一键清理内置 WebView 引擎积累的临时浏览缓存与存储数据。

### 消息中心

顶栏的消息中心是全局异步任务的操作中枢：
- 实时追踪 `批量转录`、`自动化监控`、`LLM 润色/翻译/摘要`、`数据恢复` 与 `应用更新` 的执行进度与状态（等待中、运行中、可恢复、已中断、失败、已完成）。
- **实时批量取消**：在批量转录执行期间，您可以直接在消息中心点击取消按钮，当前处理分段结束后立即停止，安全放弃后续任务，不损坏已保存文稿。
- **清空与整理**：点击清空菜单，可快捷选择 `清空已完成` 或 `清空全部` 历史任务通知。
- **恢复中心**：当因断电或异常退出导致任务中断时，可在消息中心一键恢复或丢弃未完成的批处理。

### 诊断与备份

- 在 `设置 > 常规` 中，使用 `诊断` 检查本地转录调用链、运行时就绪状态与打包环境。
- 在同一页面中，使用 `备份与恢复` 导入或导出轻量级 `.sonabackup` 归档包，其中包含应用配置、项目数据、摘要、自动化规则以及 LLM 用量统计（不包含原始音频）。

### 说明

- 在 `设置 > 词汇` 中，`热词` 按每行一个输入。热词适用于 sherpa-onnx Transducer 与 Qwen3-ASR 模型以及 llama.cpp 预设（Qwen3-ASR）。类似 `词条 :2.0` 的权重语法仅适用于 sherpa-onnx Transducer 模型。
- 在 `设置 > 词汇` 中，`文本替换` 可在转录完成后自动批量纠正特定的常见术语错别字或拼写。
- 在 `设置 > 词汇` 中，`说话人档案` 存储已知说话人的本地参考声纹样本。档案根据可用样本数量与时长会显示 `就绪 (Ready)`、`受限 (Limited)` 或 `未就绪 (Not ready)`；这些状态用于指导匹配置信度，并不限制您手动绑定该档案。

## 11. 常见问题与排障

### Sona 一直提示我完成首次设置

- 打开首页提醒横幅，完成模型下载和麦克风权限步骤。
- 如果之前跳过了引导，请确认 `设置 > 模型设置` 中已经配置好 `实时录音模型` 和 `批量转录模型`。
- 如果您之前主动隐藏了提醒横幅，可通过再次出现时的引导流程或设置入口手动重新打开。

### `实时录音` 无法开始

- 检查操作系统麦克风权限。
- 确认在 `设置 > 模型设置` 中已配置好 `实时录音模型`。
- 确认当前输入源是否正确：`麦克风` 或 `桌面音频`。

### `批量转录` 无法开始

- 确认已在 `设置 > 模型设置` 中配置 `批量转录模型`。
- 确认输入文件扩展名属于支持的音频或视频格式。
- 如果提示格式不受支持，请先转换媒体文件格式或配置有效的 FFmpeg 路径后重试。

### `LLM 润色` 或 `翻译` 不可用或报错

- 确认在 `设置 > LLM 服务` 中已填写正确的 Provider 凭据（API Key、Base URL 等）。
- 确认已在 `功能模型绑定` 中为润色指定 `润色模型`、为翻译指定 `翻译模型`。
- 点击 `测试连接` 验证服务可用性。
- 如果使用本地自建服务（例如 `Ollama`），请先确认该后台进程正在运行且端口可访问。

### 找不到 `Auto-Polish`

- 打开转录界面的 `LLM 润色 > 高级设置`，在此处可配置 Auto-Polish 开关、触发频率、关键词、指令式 `润色模式`（`去冗易读`、`逐字精准`、`书面规整`）以及自定义上下文。

### 导出时只有 `原文`

- 只有当前转录至少包含一个翻译分段时，`译文` 和 `双语` 模式才可选。

### `说话人校对` 列表为空

- `说话人校对` 依赖分段中已有的说话人声纹元数据。若录音未启用说话人分割或无多说话人标签，列表可能为空。
- 候选匹配建议依赖 `设置 > 词汇` 中的 `说话人档案`、已导入的参考样本以及当前项目所启用的档案。
- 您随时可以在编辑器中点击可见的说话人徽标，手动将该说话人绑定到某个本地声纹档案。

### 找不到 `版本快照`

- `版本快照` 仅对已包含转录分段且已保存的项目条目显示。
- 临时的 `current` 未保存转录以及仍在进行中的实时录音草稿不会显示版本快照入口。
- 快照会在执行 `LLM 润色`、`翻译`、`重新转录` 等批量改写操作之前，以及从旧快照恢复之前自动创建。

### 恢复轻量备份后无法播放音频

- 本地轻量备份归档（.sonabackup）专注于保护文稿、摘要、项目数据、自动化规则与用量统计，不打包海量音频文件。
- 恢复后的记录支持查看、搜索、二次编辑与重新导出，但若本地磁盘上缺少原始音频文件，播放器控件将不可用。

### 为什么新内容会先进入 `收件箱 (Inbox)`？

- `收件箱 (Inbox)` 是未归入任何特定项目的录音和导入内容的默认承接区。
- 如果希望新录音或导入自动归属于某个项目，请在开始 `实时录音` 或 `批量转录` 之前，先在顶栏或项目列表中打开该项目。
- 您也可以随时在 `项目中心` 中把已保存的条目从 `收件箱 (Inbox)` 移动到目标项目中。

### 删除项目后，里面的录音与转录会丢失吗？

- 不会。删除项目时，Sona 会提供弹窗选项：您可以选择将内容移至 `收件箱 (Inbox)`（保留在项目中心继续使用），或移入 `回收站`（软删除备查）。

### 为什么录音中途会看到 `草稿` 条目？

- 在活跃的实时录音进行期间，Sona 会在 `项目中心` 中创建一个可见的 `草稿` 条目，以便会话拥有已保存的位置。
- 当您停止录音时，Sona 会直接将该条目完成转为正式文稿，而不会创建重复的第二份副本。
- 在音频采集过程中，草稿即代表当前的录音会话；录音结束后，完整的转录结果可直接在该条目中继续使用。

### `实时字幕` 浮窗没有出现

- 请返回 `实时录音` 页面，确认 `实时字幕` 开关已经开启。`设置 > 字幕设置` 仅控制字幕浮窗的显示行为和外观。
- 如果您仅需要系统音频的悬浮字幕，无需点击开始录音，只需打开 `实时字幕` 即可。
- `实时字幕` 依赖同一套离线实时转录体系，请确保已在 `设置 > 模型设置` 中配置好 `实时录音模型`。

### 语音输入法无法工作

- 请前往 `设置 > 语音输入法` 确认已启用 `语音输入法`。
- 检查页面中列出的快捷键、模型、VAD、输入设备以及就绪状态是否全部正常。
- 确保已配置实时转录模型，因为语音输入法复用了离线实时转录能力。

### 在哪里恢复被中断的批量或自动化任务？

- 如果 Sona 提示存在待恢复任务，请打开顶栏的 `消息中心`。
- 在其中使用恢复入口即可一键继续或丢弃中断的批处理和自动化任务。
- 如果您需要的是系统诊断或数据备份，请前往 `设置 > 常规`。

### 底部播放器控件没有显示

- 音频播放器仅在当前转录存在可用音频源（例如已保存的录音文件或已处理的本地导入文件）时才会显示。

### 忘记了云同步主密码怎么办？

- 如果您在创建同步库时导出了 `应急恢复密钥`，可在解锁界面切换为 `使用恢复密钥重置`，输入该密钥重新设定新密码。
- 如果既忘记主密码又丢失了恢复密钥，远端加密数据将无法解密。您可以解除设备绑定并重新创建全新的同步库。

### 为什么云同步不上传原始音频文件？

- Sona 定位于隐私优先的本地工具。录音包含高度敏感的个人声纹信息，且体积庞大。
- 云同步通过端到端加密同步转录文本、摘要、项目结构与词库配置，确保多端阅读、编辑与整理体验完全同步；原始音频文件安全保留在采集设备上。

### 云同步提示并发冲突如何处理？

- 打开 `设置 > 云同步 > 冲突中心`。
- 界面会列出产生冲突的项目、转录文档或设置条目。点击条目可左右对比两端的修改时间与文本差异，自主选择 `保留当前版本`、`使用冲突版本` 或 `保留两个版本`。

### 误删的内容如何找回？

- 在 `项目中心` 的左侧边栏打开 `回收站`。
- 找到误删的条目，点击右键或使用操作栏选择 `恢复`，条目将自动还原至原所属项目或收件箱。
- 只有在回收站中点击 `彻底删除` 或 `清空回收站` 后，数据才会被永久移除。

### 批量转录执行中可以中途停止吗？

- 可以。打开顶栏的 `消息中心`，在正在运行的批量转录任务旁点击取消/停止按钮。Sona 会在当前处理片段结束后安全退出，已完成的文件会妥善保存。

### 为什么提示需要配置自定义 FFmpeg 路径？

- 导入某些特定格式的音视频文件（如部分 MP4、MKV、AAC、WMA 等）需要依赖 FFmpeg 进行音频分离与解码。
- 如果操作系统未安装全局 FFmpeg，请下载 FFmpeg 二进制并在 `设置 > 存储管理 > 自定义 FFmpeg 路径` 中指定其路径。
